# Technology logos

Original SVG icons from [Devicon v2.16.0](https://github.com/devicons/devicon/tree/v2.16.0/icons), distributed under the included MIT license. Product names and logos belong to their respective owners. Used to identify technologies in the portfolio.

The SVG files are hosted locally, so the cards and 3D network do not depend on an external icon CDN.

TypeScript, Express, Flutter, Dart, Firebase, Bootstrap, React Router, Framer Motion, Three.js, Mongoose, Axios, Git, GitHub, GitHub Actions, npm, Vite, ESLint, Vitest, Jest, Vercel, Apache Tomcat, and Eclipse use the Devicon v2.16.0 source and included MIT license. React Native uses the React logo; Cloud Firestore and Firebase Auth use the Firebase product-family logo. Expo Router shares the Expo logo, and GitHub Pages shares the GitHub logo. JSP/Servlets and JSTL use the Java logo; JDBC uses the MySQL connector ecosystem logo.

Expo, OpenStreetMap, TanStack Query, React Hook Form, Zod, Stripe, Cloudinary, JWT, Prettier, Testing Library, and Render SVGs are from [Simple Icons 16.35.0](https://www.npmjs.com/package/simple-icons/v/16.35.0), distributed under [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/). The artwork is unchanged. Logos identify the technologies and do not imply endorsement.

Libraries without a product logo use functional icons from the installed Lucide React package: editor (Tiptap), drag (dnd-kit), chart (Recharts), map (React Native Maps / Flutter Map), mail (Nodemailer), document (jsPDF / PDFKit), spreadsheet (SheetJS), capture (html2canvas), QR code (QRCode), barcode (JsBarcode / bwip-js), scan (ZXing), and test (Supertest), and shapes (Lucide React). These are category symbols rather than official brand marks. See `LUCIDE-LICENSE.txt` for the included ISC license.

Explicit 256 × 256 dimensions were added to the SVG roots for reliable WebGL texture rasterization; the logo artwork is unchanged.
